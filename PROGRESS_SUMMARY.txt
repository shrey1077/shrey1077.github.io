WHAT THIS PROJECT IS
--------------------
Not a conventional portfolio website. An interactive "Memory Palace":
- The homepage represents the designer's mind.
- A 3D anatomical brain (top view) is the centerpiece: LEFT hemisphere =
  logic (monochrome ink sketch), RIGHT = creativity (color washed into the
  same linework).
- Every client is a "memory" stored in that mind; every collection is a room;
  every asset is an artifact.
- Design philosophy: white gallery minimalism (pure #FFFFFF), museum-quality
  calm motion, storytelling over showcasing, curation over completeness.
- Constitution document: CREATIVE_INTENT.md (in the asset archive).

TECH STACK
----------
Next.js 16 (App Router, Turbopack) · TypeScript strict · Tailwind CSS v4 ·
React Three Fiber v9 + drei (WebGL brain) · Zustand (state) · Framer Motion
(UI motion) · Leva (dev-only debug panel) · GSAP (installed, reserved) ·
Fonts via next/font: Caveat (handwritten), IBM Plex Mono (technical),
Fraunces (serif display). All routes statically generated (SSG).

HARD RULES / INVARIANTS
------------------------
- Pure white background; no gradients/textures on the page itself.
- No bounce/elastic easing, no loading spinners, no stock photography.
- Nothing per-frame touches React state (refs + getState() snapshots).
- All tunables in src/constants/; content on the filesystem, never hardcoded
  in components. Dev tools (Leva) never ship to production.
- Curation before completeness; storytelling before showcasing.
