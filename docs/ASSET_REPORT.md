## Missing assets (the honest gaps)

1. **Photography** — `Pictures` is empty; the archive holds only 3 real
   photographs (installed standees). The "Photography & Media" system must lean
   on Videos + campaign visuals until real campus/student photography arrives.
2. **Birding** — named in the brief's example map; no such folder exists.
3. **Web-ready derivatives** — many heroes are heavy PDFs/PNGs (300+ MB
   folders); the experience needs curated, optimized copies (see
   CONTENT_GUIDE.md conventions), never the raw archive.
4. **Campus logo guideline pages for Mumbai** exist as PPTX only — no
   rasterized pages.

~440 files reduce to roughly **60–80 display-worthy artifacts** across six
communication systems (see CURATION_REPORT.md). Privacy-flagged folders (CV,
New Joinee, Presentations) are excluded outright.
